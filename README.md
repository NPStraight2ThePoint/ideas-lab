# Ideas Lab

A running collection of problem statements, design explorations, and implementation sketches from my work in financial systems, data engineering, and testops.

Each entry in [`/ideas`](./ideas) is a self-contained writeup of one idea: the problem, the approach considered, and what it demonstrates (and doesn't claim to solve). These range from fully implemented patterns to early-stage design notes.

This repo is updated on an ongoing basis — new ideas are added as they come up in day-to-day work, not on any fixed schedule.

## Conventions

- Each idea gets a new file in `/ideas`, numbered sequentially.
- Start a new idea from [`_template.md`](./ideas/_template.md).
- Add a row to the index table above when you add a new file.
- Status is one of: `Idea`, `In Progress`, `Implemented`, `Parked`.
